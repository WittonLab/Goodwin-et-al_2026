# GCaMP Place Cell Analysis Pipeline

Analysis pipeline accompanying **Goodwin et al. (2026)** for the processing of two-photon GCaMP imaging acquired during virtual reality behaviour.

The workflow consists of behavioural preprocessing followed by place-cell classification and odd-versus-even lap validation.

## Repository structure

```text
GCaMP/
├── 01_behaviour_preprocessing/
│   └── extract_imaging_window_vr_behavior.m
├── 02_place_cell_analysis/

│   └── helper_functions.py
└── README.md
```

## Analysis workflow

### 1. Behavioural preprocessing

Run:

```matlab
extract_imaging_window_vr_behavior.m
```

This MATLAB script extracts the portion of the virtual reality behavioural recording corresponding to the imaging session.

It generates behavioural files for the complete imaging session and, where appropriate, pre- and post-switch periods.

### 2. Place-cell classification

Run:

```text
01_GCaMP_batch_suite2p_place_cells.ipynb
```

This notebook loads Suite2p outputs and the corresponding behavioural data, processes calcium activity, constructs spatial activity maps, calculates spatial information and performs shuffle-based place-cell classification.

The notebook uses functions contained in:

```text
functions/helper_functions.py
```

### 3. Odd/even lap validation

Run:

```text
02_GCaMP_odd_even_place_cell_validation.ipynb
```

This notebook evaluates within-session spatial tuning by comparing activity maps generated from odd and even laps.

## Input data

The analysis requires:

- Suite2p output files
- behavioural files generated by the MATLAB preprocessing step

Data paths should be specified in the user settings section of each analysis script/notebook.
